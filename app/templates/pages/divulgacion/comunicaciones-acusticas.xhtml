{{ _('En nuestra vida cotidiana utilizamos Wi-Fi, Bluetooth, telefonía celular y otras tecnologías inalámbricas para comunicarnos. Pero ¿qué ocurre cuando queremos comunicarnos debajo del agua?') }}

{{ _('En el medio acuático, y especialmente en el agua de mar, las ondas electromagnéticas utilizadas habitualmente para las comunicaciones inalámbricas se atenúan rápidamente.') }}

{{ _('El sonido es una onda mecánica y necesita un medio material para propagarse, como el aire o el agua.') }}

{{ _('En el agua de mar, el sonido se propaga aproximadamente a 1500 metros por segundo, aunque su velocidad depende de factores como la temperatura, la salinidad y la presión.') }}

{{ _('El transmisor genera una onda acústica que se propaga por el agua hasta el receptor, a ~1500 m/s.') }}

{{ _('Algunas magnitudes que caracterizan a una onda acústica y a su propagación en el agua:') }}

  • {{ _('Frecuencia') }}: {{ _('cantidad de oscilaciones por segundo, medida en hertz (Hz).') }}
  • {{ _('Longitud de onda') }}: {{ _('distancia entre dos crestas consecutivas de la onda.') }}
  • {{ _('Velocidad de propagación') }}: {{ _('en el mar, cercana a 1500 m/s; varía con la temperatura, la salinidad y la presión.') }}
  • {{ _('Atenuación') }}: {{ _('pérdida de energía de la señal a medida que se propaga.') }}
  • {{ _('Ruido') }}: {{ _('sonidos del ambiente (olas, embarcaciones, fauna marina) que se mezclan con la señal.') }}
  • {{ _('Reflexiones') }}: {{ _('rebotes de la señal en la superficie y el fondo del mar.') }}
  • {{ _('Propagación multicamino') }}: {{ _('la señal llega al receptor por varios caminos a la vez, con distintos retardos.') }}
